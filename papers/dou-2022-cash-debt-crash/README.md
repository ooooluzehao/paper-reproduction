- 原始本地项目位于 `D:\存贷双高论文复现`。仓库脚本位于本篇 `code/` 下的同名阶段目录；本篇数据快照已显式允许入库，dta/xlsx/zip由Git LFS跟踪。

## 复现步骤

### 1. 准备输入

本篇已追加现有数据快照，原始Excel和各阶段dta位于code对应阶段，根目录数据压缩包位于data-archives。文件清单及校验值见docs/data-manifest.json。数据状态未在此次上传中重新核验；历史验证记录不一定对应最新数据。

### 2. 导入并纵向合并周收益率

目录 `code/02数据整理/`，运行 `数据整理.do`，再运行 `数据合并.do`。

输入：TRD_Week.xlsx及编号分片、TRD_Weekm.xlsx。输出：`个股周收益率合并.dta`、`市场周收益率合并.dta`。

重要：当前脚本只导入TRD_Week.xlsx、TRD_Week1.xlsx、TRD_Week2.xlsx；本地还有TRD_Week3.xlsx，须先确认是否应追加。不要把不完整导入当作最终结果。

### 3. 匹配个股和市场收益率

将上一步两个输出放到 `code/03合并个股周收益率与市场周收益率/`，运行 `合并市场收益率.do`。

按交易周份、市场类型进行m:1匹配，输出 `周收益率.dta`。现有脚本只保留匹配记录，执行前后应记录未匹配数量。

### 4. 生成市场前后期变量并用Python回归

把 `周收益率.dta` 放到 `code/04计算股市崩溃/`。

`计算股价崩溃回归前.do` 已含原来的慢速Stata循环。采用Python时，只运行从开头到 `egen long firmyear = group(stock year)` 的准备部分，跳过后面的初始化和回归循环，然后执行：

```stata
save "周收益率_回归前.dta", replace
```

在终端运行：

```bash
python "code/04计算股市崩溃/Python公司年度回归.py"
```

该命令从本篇论文目录执行；脚本按自身路径读取同目录dta。按stock、year分别OLS回归，要求完整记录至少30周及矩阵满秩，输出 `周收益率_回归完成.dta` 和本地 `Python回归核验.json`。回归输出epsilon、Nreg、reg_ok，清空中断后部分结果再重算。

市场模型采用现金红利再投资个股收益率、流通市值加权的对应市场收益率及前后两期。正文未明确这些全部细节，属于待核对实现。

### 5. 计算年度崩盘风险并对齐年份

同一阶段目录，先清空Stata内存，再运行 `计算股价崩溃回归后.do`。

W=ln(1+epsilon)；计算NCSKEW和自然对数DUVOL，保留每公司每年一行。将实际风险年份risk_year减1生成解释变量year，输出 `崩盘风险.dta`。

例如2008年的风险放在year=2007这一行，不要后续重复前推。目前脚本保留Ninvalid==0整年排除规则，见已知问题。

### 6. 整理资产负债表

目录 `code/05处理资产负债表数据/`，输入FS_Combas.xlsx，运行 `数据整理.do`。

重命名变量，证券代码转数值，截取日期提取年份/月/日；保留12月31日、A类合并报表。输出 `资产负债表.dta`。

### 7. 整理并合并行业信息

目录 `code/06处理公司行业代码/`，输入STK_LISTEDCOINFOANL.xlsx，运行 `数据整理.do`，生成 `公司行业代码.dta`。

将该文件和资产负债表放到 `code/07筛选存贷双高公司/`，运行 `merge公司行业代码.do`，得到 `存贷双高计算前.dta`。现有代码保存名称引号内有尾部空格，实际使用前请检查文件名。

### 8. 构造存贷双高DH

在第7阶段目录运行 `筛选存贷双高.do`。计算货币资金/总资产及短期借款/总资产；取年度行业均值；两项比例都大于20%并高于各自行业均值，且连续两年满足，DH=1。

最新代码已修正：任意一年明确不满足时DH=0；两年都满足时DH=1；无法判断时缺失。`L.`要求上一自然年存在。

现有行业是非制造业首字母、制造业前两字符C1–C4，未经作者口径确认。22类包含金融J、房地产K，不能据此认定分类正确。

输出 `存贷双高.dta`。保留DH=0对照样本，不仅保存双高公司。

### 9. 合并核心X和Y

将 `崩盘风险.dta`、`存贷双高.dta` 放到 `code/08合并XY变量/`，运行 `merge.do`。

按stock、year一对一合并；风险文件stock先转数值。输出 `合并核心变量完毕缺少控制变量.dta`。匹配成功仍可能含变量缺失。
