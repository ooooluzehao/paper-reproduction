# 数据准备与字段

按仓库所有者明确要求，本篇已有数据和生成的公司级结果作为2026-10-11快照发布，dta/xlsx/zip由Git LFS管理。数据使用仍需符合CSMAR授权。暂不将数据单位、字段旧准则映射或缺失值替代作未经核对的假定。

| 输入 | 关键字段 | 使用阶段 |
| --- | --- | --- |
| TRD_Week.xlsx、Week1、Week2（Week3不纳入） | 证券代码、交易周份、周开盘日期、现金红利再投资周个股回报率、市场类型、周个股总市值 | 02 |
| TRD_Weekm.xlsx | 市场类型、交易周份、三类现金红利再投资市场回报率 | 02 |
| FS_Combas.xlsx | 证券代码、证券简称、统计截止日期、报表类型、货币资金、短期借款、资产总计等 | 05 |
| STK_LISTEDCOINFOANL.xlsx | 股票代码、统计截止日期、行业代码C、行业名称C、股票简称 | 06 |

解释变量2007–2018；风险变量2008–2019。至少保留2006财务数据判断2007连续两年条件。若Abacc采用前三年DA移动合计和修正Jones估计，需要更早数据，建议准备2003–2018并核对2007年前字段。市场前后期在限定风险年份前构造。

财务映射：cash=货币资金；short_debt=短期借款；total_assets=资产总计；receivables=应收账款净额；fixed_assets=固定资产净额；parent_equity=归母权益；total_equity=全部所有者权益。stock在风险数据是六位字符串，财务为数值，合并时统一。

控制变量尚需利润表、现金流量表、年度ST/PT状态、准确行业、换手率、审计机构、前十大股东持股、注册省份、市场化指数及季度ROE信息。DA、Abacc、Zscore、Ret、MB等详细口径需附件确认。
