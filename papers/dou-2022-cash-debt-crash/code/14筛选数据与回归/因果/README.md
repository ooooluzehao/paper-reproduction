# 筛选缩尾与基准回归

本阶段使用第13阶段合并主表，通过Stata包直接输出描述性统计、Pearson相关性矩阵和两列固定效应回归。DA_csv、Abacc_csv按用户选择暂用来源值，正式DA/Abacc另做；这些结果尚不能称为完成论文正式口径复现。

## 文件与执行

|文件|用途|
|---|---|
|baseline.do|最新版精简脚本：全局变量、缺失筛选、行业/ST筛选、缩尾、输出、两条回归|
|添加ROE与ROEGROWTH.dta|29,108条输入主表，与第13阶段主表逐值一致|
|描述性统计.docx|sum2docx输出，14,572条筛选后样本|
|相关性矩阵.docx|corr2docx输出Pearson下三角矩阵与显著性星号|
|两列基准回归.docx|reg2docx输出，公司和年份×行业固定效应，公司聚类|

```stata
cd "$paper/code/14筛选数据与回归/因果"
do "baseline.do"
```

需要Stata 18及已安装的winsor2、sum2docx、corr2docx、reg2docx、reghdfe及其依赖。仓库仅去掉本机绝对cd，公式与统计命令保持不变。Word文件正在被打开时应先关闭，避免导出r(603)。

## 顺序及方法

1. 最前面全局定义12项基准控制变量：Size、MB、ROA、Ret、Dturnt、GROWTH、Big4、Index、Zscore、Disp、DA_csv、Abacc_csv。
2. 用rowmiss删除模型数值字段及stock/year/STPT缺失；另删除industry缺失。不要求所有审核字段非缺失，也不因补充ROE缺失删样。
3. 按industry剔除J金融业、K房地产业公司年份。
4. 剔除当年STPT==1，不按公司全部历史删除。
5. `winsor2 $continuous, replace`全样本两端各1%缩尾，使用包默认分位点，不写cuts()，不按年；DH、Big4不缩尾。
6. sum2docx输出N、min、max、mean、sd；corr2docx输出Pearson矩阵；不手写统计表或相关系数。
7. 用两条独立reghdfe分别估计FNCSKEW/FDUVOL，对应论文式(3)、表4第(3)(4)列，吸收stock与year_industry，按stock聚类；不使用单次双向去均值。
8. reg2docx输出系数、公司聚类t值、样本数、R²及固定效应标记。风险变量已经对齐次年，不再次前移。

ROEGROWTH不进入此基准控制变量清单：原文在盈余管理机制检验中说明，用ROEGROWTH替换DA/Abacc。该字段及ROE仍保留在输入主表，后续机制检验可用。

最新版源脚本目前没有save命令，只输出三份Word表，不保存各阶段或处理后的dta；以用户当前文件为准，不重新添加被用户移除的保存步骤。未上传已经删除的旧日志、旧四列回归表、旧筛选dta或历史审核稿。

## 实际核验

输入29,108条，按模型及筛选字段删除缺失后15,823条，剔除J/K后14,981条，剔除ST/PT后14,572条，DH=1有163条。reghdfe默认递归去除单例后两列实际样本均为14,405条，比完整样本少167条。

脚本统计部分已通过Stata MP 18执行，三份Word表已通过原生Word转PDF及页面图像检查；本次同步读取最新版源文件，独立核验输入与第13阶段一致、筛样行数与导出表一致。仓库副本只有路径适配，本次上传未再运行整篇复现。

两列DH系数为0.0377和0.0071，t值为0.500和0.145，目前均不显著。暂用来源DA/Abacc，MB等上游定义仍需核对；不能为了贴近论文样本数或显著性改变规则。
