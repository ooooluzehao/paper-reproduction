# ROEGROWTH计算与合并

先cd到本阶段目录，依次运行`计算并合并ROEGROWTH.do`、`合并年度ROE到主表.do`。仓库默认入口读取已上传的数据库查询快照，无需数据库账号。`数据库读取并计算ROEGROWTH.do`保留在线查询版本，需要本机配置`csmar_get`及两个已注册入口；刷新后结果可能随数据库更新而变化。原始研究目录的do使用在线查询，仓库副本使用相对路径和离线快照。

## 计算步骤与原因

1. 从 `balancesheet` 读取2006—2018年合并报表季度末所有者权益合计 `a003000000`。保留03-31、06-30、09-30、12-31，排除1月1日等其他日期，避免一个自然季度出现多个报告日期。2006年用于计算2007年第一季度所需的上一季度ROE。
2. 从 `profitability` 读取 `f050501b`，保留合并报表A和定期报告 `source=0`。该字段使用年初至报告期累计净利润，保存为 `ROE_cum_db` 供核对，不直接拿来计算单季度增长率。
3. 从既有 `10添加利润表相关控制变量/利润表_全部整理.dta` 读取合并报表累计净利润。第一季度的单季利润等于累计值，第二至第四季度的单季利润等于当前累计值减上季度累计值。`xtset stock qdate` 后使用 `L.`，季度缺口不会当作相邻季度。
4. 单季度 `ROE_q = net_profit_q / equity_end`。分母为季度末合并总权益，与数据库ROE A的分母定义一致；分子还原为单季净利润。总权益小于等于零或缺失时ROE设为缺失，记录保留。该单季度口径是本次实施选择，不将数据库累计ROE或TTM ROE当作单季度值。
5. `ROEGROWTH_q = (ROE_q - L.ROE_q) / L.ROE_q`。上一季度ROE为零或任一期缺失时增长率缺失；负基期按原式保留，不取绝对值。先计算跨年滞后，再保留2007—2018年。
6. 按用户选择，将公司当年季度增长率取平均。Stata的 `egen mean()` 忽略缺失，因此不足四个有效季度时，当前保存的是有效季度均值；同时保存 `ROEGROWTH_Nquarter` 和 `ROEGROWTH_complete`。若最终研究口径要求四季齐全，可在之后统一筛样阶段用完整标记，本步骤不额外删样。年度汇总方式为用户选择，不声称论文明确规定了年度平均方法。
7. 按 `stock year` 合并到 `12添加市场化指数/添加Index.dta`，另存 `添加ROEGROWTH.dta`。只保留主表已有记录，原文件和原字段不改变，不剔除控制变量缺失记录、不缩尾。

## 本次运行核对（2026-10-12）

- 季度明细123,001条，年度计算表32,298条，主表29,108条。所有主表公司年份均找到年度记录；其中1,467条ROEGROWTH缺失，记录保留。
- 主表有效季度数：0季1,467条；1季589条；2季45条；3季1,118条；4季25,889条。
- 用原利润表累计净利润除以季度末权益，与数据库ROE A核对：可比较记录最大绝对差约0.0000005，与数据库六位小数舍入一致。
- Python逐字段核对主表原字段和记录均未改变；年度均值与季度明细重新汇总的结果一致。
- 增长率在上一季度ROE接近零时可能很大，保存原值，之后与其他控制变量一起按最终规则处理。
- 当前数据库查询读取发布视图。已保存查询数据便于复核；将来重跑可能随数据库更新而变化，不声称固定了数据库发布批次。

## 年度ROE补充合并

`合并年度ROE到主表.do`从累计ROE查询快照选当年12月31日，构造年度ROE A（全年合并净利润/年末合并总权益），保存`ROE_公司年度.dta`，再匹配到已经含ROEGROWTH的主表，另存`添加ROE与ROEGROWTH.dta`。ROE与ROEGROWTH是两个独立字段，年度ROE不取季度ROE的平均值。

已通过Stata运行及逐字段回读核对：新主表29,108行，公司年度键唯一，ROE缺失300行，ROEGROWTH缺失1,467行，原有字段不变。不剔除缺失，不缩尾。
