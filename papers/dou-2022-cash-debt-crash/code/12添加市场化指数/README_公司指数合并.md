# 先省份年度指数，再公司年度指数

本次使用用户新提供的“2007-2018企业省份+市场化指数合并.dta”中的完整总指数，不混用先前17页报告节选的总指数。原文件、原报告录入表和第11步主表均保持原样。

## 顺序与运行

从本目录在Stata运行：

```stata
do "01构建省份年度指数.do"
do "02补充公司省份并匹配指数.do"
```

也可整体执行“合并公司省份与市场化指数.do”。

1. 第一步统一指数文件省份简称和规范名称/六位代码。先检查同省份同年份总指数与各方面指数一致，再每个省份年份保留一条，得到“省份年度市场化指数_完整2007至2018.dta”。31省份×12年=372条，province_code/year唯一。Index=ln(1+market_index_raw)。同时另存指数来源企业年度省份对照，供下一步补充公司省份。
2. 第二步从第11步29,108条主表出发，匹配用户年度province.dta。原主表省份字段不覆盖，本次匹配使用province_for_index和province_code_for_index。年度省份表优先（25,980条），其缺失时用指数企业文件省份（2,690条），剩余438条从本地国泰安年度基本信息取同年12月31日省份。province_source分别标记1/2/3，不跨年填充。
3. 最后按province_code_for_index/year与第一步表做m:1匹配，不要求公司必须出现在指数企业清单。全部29,108条Index非缺失。另存独立“公司年度市场化指数.dta”及“添加市场化指数_全部企业_未删缺失未缩尾.dta”。前者便于后续只按stock/year合并Index，后者保留全部现有主表字段和审核信息。

两份企业省份来源存在不一致，province_conflict保留该标记，本步骤明确年度省份表优先。market_direct保留指数企业来源的原总指数，最终market_index_raw按本次使用的年度省份和年份取值。

本地补充来源为已处理的companyinfo批次44e1c459442938e64d768a49，仅只读取得438条公司同年省份；补充CSV与来源哈希保存在合并来源目录和合并来源记录.json。未修改数据库，未把另一年度省份冒充本年省份。

三份do已经在Stata MP 18实际运行。独立核验372条省份年度唯一键、29,108条公司年度唯一键、公司值与省份年度值一致，Index公式正确；新主表全部旧字段逐值不变。详情见公司指数合并核验.json。本步不删缺失、不缩尾，不执行ST/PT或行业筛选。
