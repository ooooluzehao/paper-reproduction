# 市场化指数省份年度对照表

来源：王小鲁、樊纲、胡丽芳《中国分省份市场化指数报告（2018）》用户提供的17页扫描节选，PDF第15页、书内第5页、表1-1。

原表只有2008、2010、2012、2014、2016五个年份，31个省份，共155个总指数值，按原表保留两位小数。全国平均行不作为省份观测。

- 市场化指数_原表年份.csv/.dta：仅155条实际报告值。
- 市场化指数_原表宽表.csv：按原表布局核对五年数值。
- 市场化指数_2007至2018匹配模板.csv/.dta：372条省份年度记录，217条没有原表数值，reported=0；缺失值保留，不填充。
- 市场化指数_省份年份对照表.xlsx：原表长表、宽表、匹配模板及来源说明。
- 生成市场化指数DTA.do：从两个长表CSV生成带标签的Stata文件，不修改已有公司表。

province_code为匹配附加的省级六位代码；market_index_raw是原表总指数（分），Index=ln(1+market_index_raw)为派生变量。没有将报告年份2018当作指数观测年份，也没有自动补齐2007、2009、2011、2013、2015、2017、2018。
